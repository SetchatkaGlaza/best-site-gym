# Сайт фитнес-клуба BEST

Одностраничный сайт фитнес-клуба BEST (Вологда, ул. Гагарина, 83).
Версия 1.0.0, октябрь 2026.

Сайт состоит из обычных файлов (HTML, CSS, JavaScript и изображения). Ему не нужны база данных,
панель управления, подписки на сервисы и специальный хостинг. Он работает на любом хостинге,
открывается быстро и не ломается при обновлениях.

## 1. Что входит в проект

```
best-site/
├── index.html            главная страница: все тексты, цены, график, контакты
├── 404.html              страница «Не найдено»
├── css/
│   └── style.css         оформление сайта (цвета, шрифты, адаптивность)
├── js/
│   └── main.js           поведение: подбор абонемента, фильтр тарифов, вопросы, индикатор «Открыто»
├── images/               фотографии клуба, логотип, иконки, картинка для соцсетей
├── favicon.ico           значок во вкладке браузера
├── site.webmanifest      данные для установки сайта на экран телефона
├── robots.txt            инструкция для поисковых роботов
├── sitemap.xml           карта сайта для поисковых систем
├── .htaccess             настройки сервера Apache (сжатие, кеш, страница 404)
├── CHANGELOG.md          история версий
└── README.md             этот файл
```

Что умеет сайт:

- показывает цены, условия, график работы, галерею, отзывы и контакты клуба;
- **подбирает абонемент** по числу тренировок, времени и категории посетителя;
- **показывает статус «Сейчас открыто / закрыто»** по графику работы клуба (время считается по Москве);
- фильтрует тарифы по категориям;
- корректно выглядит на телефоне, планшете и компьютере, поддерживает светлую и тёмную тему;
- ведёт посетителей в группу VK, Telegram и карточку на Яндекс Картах.

## 2. Как запустить сайт

### Вариант А. Обычный хостинг (рекомендуется)

1. Зарегистрируйте домен, например `bestvologda.ru`, и закажите хостинг (подойдёт любой тариф с поддержкой
   статических сайтов).
2. Загрузите **содержимое** папки `best-site` (а не саму папку) в корневую папку сайта на хостинге.
   Обычно она называется `public_html`, `www` или `htdocs`. Файл `index.html` должен лежать прямо в корне.
3. Включите бесплатный сертификат HTTPS в панели хостинга.
4. Откройте адрес сайта и проверьте работу по [списку из раздела 3](#3-что-сделать-перед-запуском).

### Вариант Б. Бесплатные площадки

GitHub Pages, Cloudflare Pages и Netlify принимают такие сайты бесплатно: создайте проект и загрузите
файлы. Затем в настройках площадки подключите свой домен.

### Вариант В. Проверка на компьютере

Откройте файл `index.html` двойным щелчком. Интернет для этого не нужен.

## 3. Что сделать перед запуском

### Обязательно

- [ ] **Указать адрес сайта.** В файлах `index.html`, `robots.txt` и `sitemap.xml` найдите
      `https://your-domain.ru` и замените на реальный адрес сайта, например `https://bestvologda.ru`
      (в редакторе это делается командой «Найти и заменить во всех файлах»).
- [ ] **Проверить цены.** Цены взяты из публичных страниц клуба (группа VK и Яндекс Карты).
      Сверьте их с действующим прайс-листом (см. [раздел 4.2](#42-цены-и-тарифы)).
- [ ] **Проверить график работы** и телефон (см. [раздел 4.1](#41-график-работы-и-контакты)).
- [ ] **Подтвердить условие «первое занятие бесплатно».** Оно взято из отзывов клиентов. Если акция не
      действует, удалите упоминание (текст встречается в разделах «Как начать», «Условия» и «Контакты»).

### Рекомендуется

- [ ] Проверить права на использование фотографий и логотипа, особенно кадров, на которых есть люди.
- [ ] Заменить фото на актуальные и более качественные (см. [раздел 4.3](#43-фотографии)).
- [ ] Добавить сайт в карточку клуба на Яндекс Картах и в группу VK (поле «Сайт»).
- [ ] Подключить счётчик посещаемости (см. [раздел 5](#5-поисковая-оптимизация-и-аналитика)).

### Проверка после публикации

- [ ] Все разделы открываются, картинки на месте, нет сообщений об ошибках.
- [ ] Сайт нормально выглядит на телефоне.
- [ ] Ссылки на VK, Telegram и Яндекс Карты открываются, телефон набирается нажатием.
- [ ] Адрес без `www` и с `www`, а также `http` и `https` ведут на одну и ту же страницу.
- [ ] Несуществующий адрес (например, `/test`) показывает страницу 404.

## 4. Как менять содержимое

Файлы редактируются в любом текстовом редакторе (VS Code, Notepad++, Sublime Text; обычный «Блокнот»
тоже подойдёт). Сохраняйте файлы в кодировке **UTF-8**. После правки загрузите изменённый файл на хостинг
и обновите страницу в браузере (при необходимости нажмите Ctrl+F5).

### 4.1 График работы и контакты

График хранится в **трёх местах**, правьте все:

| Где | Что менять |
| --- | --- |
| `index.html`, раздел «Контакты» | таблица `<table class="hours">` (строки по дням недели) |
| `js/main.js`, блок «Настройки» | константа `SCHEDULE` (индикатор «Сейчас открыто») |
| `index.html`, `<head>` | блок `application/ld+json`, поле `openingHoursSpecification` (для поисковиков) |
| `index.html`, подвал | краткий график в колонке «Режим работы» |

Формат в `js/main.js`: `день недели: [час открытия, минута, час закрытия, минута]`. Воскресенье имеет номер 0,
понедельник 1, суббота 6.

Телефон, ссылки VK, Telegram и Яндекс Карт: найдите в `index.html` через поиск `+7 (911) 525-32-31`,
`tel:+79115253231`, `vk.ru`, `t.me`, `yandex.ru/maps` и замените значения.

### 4.2 Цены и тарифы

Каждый тариф в `index.html` описан одним блоком:

```html
<article class="tariff" data-plan="unlimited" data-category="month" data-popular data-price="2400" data-reveal>
  <h3 class="tariff__title">Безлимит</h3>
  <p class="tariff__text">Любое время, любое число тренировок.</p>
  <p class="tariff__price">2&nbsp;400&nbsp;₽ <span class="tariff__unit">/ 30 дн</span></p>
</article>
```

Чтобы изменить цену, поправьте **два значения**: число в `data-price` (без пробелов) и видимый текст в
`tariff__price`. Калькулятор «Подбор абонемента» берёт цены из `data-price`, отдельно в скрипте их менять
не нужно.

Назначение атрибутов:

- `data-category`: вкладка, в которой показывается тариф (`long`, `month`, `own`, `promo`, `personal`);
- `data-popular`: тариф показывается на вкладке «Популярные» (уберите атрибут, чтобы скрыть);
- `tariff--featured` в классе: добавляет отметку «Хит»;
- `data-plan`: служебное имя для калькулятора (не меняйте у тарифов, которые в нём участвуют).

Разовое посещение (400 ₽) задано в `index.html` атрибутом `data-single-visit` у раздела `id="picker"` и в
тексте под тарифами.

Новый тариф: скопируйте любой блок `<article class="tariff">` и поменяйте тексты и значения.

### 4.3 Фотографии

Фотографии лежат в папке `images/`. Чтобы заменить фото, сохраните новое под **тем же именем**
(`hero.jpg`, `trainer.jpg` и так далее). Рекомендации:

- формат JPG, ширина 1100–1600 пикселей, вес до 150 КБ (сожмите на сервисе вроде squoosh.app);
- пропорции фото в галерее подстраиваются сами. Если новое фото имеет другие размеры, измените атрибуты
  `width`, `height` и значение `--ratio` (ширина, делённая на высоту) в соответствующем блоке галереи
  `index.html`;
- `hero.jpg` (фон главного экрана) лучше брать горизонтальным, тёмным и без мелких деталей;
- `og-image.jpg` (1200×630) показывается при отправке ссылки в мессенджерах и соцсетях.

### 4.4 Тексты, отзывы, вопросы

Все тексты лежат в `index.html` в открытом виде. Разделы подписаны комментариями вида
`<!-- Контакты -->`. Отзывы находятся в блоках `<figure class="review">`; чтобы добавить новый,
скопируйте блок и поменяйте имя, дату и текст (инициалы для аватара вписываются вручную).
Частые вопросы: блоки `<div class="faq__item">`.

### 4.5 Цвета и оформление

В начале `css/style.css` находятся переменные: `--accent` (основной яркий цвет), `--bg` (фон),
`--text` (цвет текста). Светлая тема описана ниже в блоке `@media (prefers-color-scheme: light)`.

## 5. Поисковая оптимизация и аналитика

Что уже сделано: описание страницы и заголовок, карта сайта, `robots.txt`, структурированные данные о
клубе (адрес, телефон, график, координаты) для поисковиков, предпросмотр ссылки в соцсетях, быстрая
загрузка, версия для телефонов.

Что рекомендуется сделать после запуска:

1. Добавить сайт в **Яндекс Вебмастер** и Google Search Console, подтвердить права и отправить `sitemap.xml`.
2. В **Яндекс Бизнесе** указать адрес сайта в карточке организации.
3. Подключить **Яндекс Метрику**: создайте счётчик и вставьте выданный код в `index.html` перед закрывающим
   тегом `</head>`. Цели для отслеживания: клик по телефону, переход в VK, Telegram, на Яндекс Карты.
4. Если подключаете счётчик или формы, добавьте на сайт уведомление об обработке данных в соответствии с
   законом о персональных данных (152-ФЗ). Сейчас сайт не собирает и не хранит никаких данных посетителей.

## 6. Технические характеристики

| Параметр | Значение |
| --- | --- |
| Тип | статический сайт (HTML5, CSS3, JavaScript ES2018) |
| Внешние зависимости | отсутствуют (нет библиотек, шрифтов и скриптов сторонних сайтов) |
| Вес страницы | около 1,1 МБ вместе с фотографиями, большая часть фото загружается по мере прокрутки |
| Адаптивность | от 320 px (маленькие телефоны) до 1920 px и шире |
| Темы | светлая и тёмная, переключаются автоматически по настройкам устройства |
| Браузеры | актуальные Chrome, Edge, Firefox, Safari, Яндекс Браузер (последние 2 года выпуска) |
| Доступность | управление с клавиатуры, ссылка «Перейти к содержимому», подписи для экранных дикторов, учёт настройки «уменьшить анимацию» |
| Работа без JavaScript | содержимое и ссылки доступны; интерактивные элементы (подбор абонемента, вкладки) отключаются |
